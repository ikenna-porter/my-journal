# Rules

* Use these terms exactly, in docs, OpenSpec artifacts, the UI and code (`observation`, `observation_reply`, `direct_conversation`, `reflection`).
* Don't use synonyms. In particular, don't say "chat" or "chat session" (say **conversation**), "insight" as a noun for the feature (say **observation**), "summary" for the saved record (say **Collaborative Reflection**), or "Path A" / "Path B".
* To add a term, add it here first.

# Terms

| Term | Meaning | Not to be confused with |
|---|---|---|
| **Entry** | A journal entry the user writes in Markdown, with an optional mood/energy tag (voice notes and photos come in v2). Immutable once saved; can be deleted. | Chunk |
| **Chunk** | A piece of an entry (or of a Collaborative Reflection), stored with its embedding for retrieval. | Entry |
| **Observation Mode** | The automatic AI mode that runs after an entry is saved. | Conversation Mode |
| **Observation** | A single message of about 5 sentences, generated by Observation Mode, that draws insight from similar past chunks and cites their entries. Only shown when the confidence threshold is met. | Collaborative Reflection |
| **Confidence threshold** | The minimum retrieval score needed for an observation to be shown. Below it, the AI stays silent. | |
| **Conversation Mode** | The AI mode the user starts: a multi-turn conversation about the entry just written. | Observation Mode |
| **Observation Reply** | A Conversation Mode conversation that starts when the user responds to an observation. | Direct Conversation |
| **Direct Conversation** | A Conversation Mode conversation that the user starts without an observation. | Observation Reply |
| **Conversation transcript** | The raw messages of a conversation. Stored separately, never shown in the journal or retrieved, deleted after 30 days. | Collaborative Reflection |
| **Collaborative Reflection** | The optional permanent record that closes a conversation, written by the user or the AI. Attached to the entry, embedded and tagged `ai_assisted`. Short form: **reflection**. | Observation, conversation transcript |
| **Retrieval** | The hand-built search that finds relevant chunks (keyword + vector search, fusion, reranking, metadata filters). | |
| **Deletion cascade** | Deleting an entry also deletes its chunks, and every reflection, observation, conversation transcript and trace that references it. | |
