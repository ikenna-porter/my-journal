# Decision

All AI features can be skipped: observations, both conversation paths, and the Collaborative Reflection that closes a conversation.[^ike-2026-11-22] If a user leaves a conversation without writing a reflection, nothing breaks and no reflection is saved.

This follows the PRD's principle that "the user is always in control" ([PRD section 2](../product/prd.md)).

[^ike-2026-11-22]: Ike: "all the AI features are skippable/optional."
